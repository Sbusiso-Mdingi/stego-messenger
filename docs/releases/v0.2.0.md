# v0.2.0 — Evaluation Framework Foundation

This release turns the original proof of concept into an open-source research toolkit centred on **measurable, reproducible evaluation**.

## Highlights

- AES-256-GCM authenticated encryption with scrypt password-based key derivation.
- Length-prefixed LSB framing with explicit capacity validation.
- Reproducible image attacks with deterministic noise.
- MSE, PSNR, BER, payload-capacity utilisation, and transparent LSB diagnostics.
- Automated pytest suite and GitHub Actions CI.
- Apache-2.0 licensing plus contribution, security, governance, roadmap, and citation files.

## Important compatibility note

The v0.2 payload and metadata formats intentionally break compatibility with the original prototype. Existing v0.1 stego packages must be treated as legacy artifacts.

## Research posture

The project does not claim reliable resistance to JPEG compression, resizing, cropping, advanced steganalysis, or targeted adversaries. Those are empirical questions for the benchmark suite, not marketing claims.
